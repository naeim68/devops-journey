# 🌍 شبکه و Name Resolution

## `ping`
برای بررسی ارتباط:
```bash
ping google.com
```

## Name Resolution (DNS)
تبدیل نام دامنه به IP توسط DNS. مثال: `google.com → 142.250.74.14`

## انواع سرورها
| نوع | وظیفه | توضیح |
|:--|:--|:--|
| DNS | ترجمه نام به IP | Name Resolution |
| NAT | اشتراک اینترنت بین کلاینت‌ها | Network Address Translation |
| DHCP | تخصیص خودکار IP | Dynamic Host Configuration Protocol |

## فرم‌های متداول سوییچ‌ها
| نوع | مثال | توضیح |
|:--|:--|:--|
| Single Dash (-) | `rm -rf` | سبک Unix |
| Double Dash (--) | `rm --recursive` | سبک GNU |
| Without Dash | `ps aux` | سبک BSD |
