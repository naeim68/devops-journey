# 🎯 Wildcard و Regex

- **Wildcard** برای نام فایل‌ها.
- **Regex** برای محتوای فایل‌ها.

فرض فایل‌ها:
```
m, m2, man, mbn, mefghn, mz,
s, s123e, s5, s6, sr567, mbz8, msaf500
```

| دستور | عملکرد |
|:--|:--|
| `ls m*` | همهٔ m* |
| `ls s*` | همهٔ s* |
| `ls ???` | دقیقاً ۳ کاراکتر |
| `ls m?*` | m + حداقل یک کاراکتر |
| `ls s????` | ۵ کاراکتر با s شروع |
| `ls m[c-f]*` | دومین کاراکتر بین c..f |
| `ls m[!b-f]*` | دومین کاراکتر خارج از b..f |
| `ls s[1,6,r]*` | دومین کاراکتر 1،6 یا r |
| `ls m[!c-f][x-z]*` | دومین خارج c..f و سوم x..z |
| `ls m{ef,a,saf}*` | بعد از m یکی از ef|a|saf |
