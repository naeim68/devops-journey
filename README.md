# 🚀 DevOps Journey – مسیر مهندسی زیرساخت من

این مخزن، مستند یادگیری من در مسیر تبدیل شدن به **DevOps Engineer / Infrastructure Engineer** است.  
این یادگیری با تمرکز بر **Linux → Networking → Shell → Storage → Automation → Monitoring → Docker → Kubernetes → CI/CD** پیش می‌رود.  
این پروژه یک **Living Repository** است و روزانه آپدیت می‌شود.
