# DevOps Journey by Naeim Ahmadian

این ریپو مسیر یادگیری من در حوزه Linux, Network, DevOps و Monitoring است.  
تمام نوت‌ها، تنظیمات و اسکریپت‌هایی که در طول یادگیری می‌نویسم، اینجا نگهداری می‌شن.

## ساختار ریپو
- 01-Linux → یادگیری لینوکس، دستورات، Bash
- 02-Network → مفاهیم شبکه و پیکربندی
- 03-DevOps → Docker، Kubernetes، Ansible و ابزارهای CI/CD
- 04-Monitoring → Zabbix، ELK، Prometheus، Nginx metrics
- 05-Security → امنیت لینوکس و سرور
- cheatsheets → خلاصه‌ها و دستورات مهم
- daily-learning → لاگ روزانه‌ی یادگیری

---
> هر روز حداقل یک یادداشت جدید اضافه می‌کنم تا مسیر یادگیری مستمر حفظ شود.
