# 💽 بررسی فضای دیسک با `du`

| دستور | عملکرد |
|:--|:--|
| `du /boot` | فضای پوشه (خام) |
| `du -h /boot` | خوانا (KB/MB/GB) |
| `du -h /boot/*` | فضای فایل‌های داخل |
| `du -ch /boot/*` | مجموع کل در انتها |

## Pipe و جریان‌های استاندارد
- **stdin (0)**، **stdout (1)**، **stderr (2)**
- مثال Pipe:
```bash
ls -l /boot | grep efi
```
